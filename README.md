## Giới thiệu

Đây là bài thực hành xây dựng Blog Listing Page sử dụng Next.js và Tailwind CSS. 
Dự án được xây dựng nhằm áp dụng các kiến thức về Next.js App Router, tạo các component có thể tái sử dụng và thiết kế giao diện responsive cho nhiều kích thước màn hình.

Website sử dụng REST API từ JSONPlaceholder để lấy và hiển thị danh sách các bài viết. 
Người dùng có thể xem danh sách bài viết trên trang chính và truy cập vào từng bài viết thông qua trang Blog Detail với dynamic route `/blog/[id]`.

## Công nghệ sử dụng

- NextJS
- Tailwind CSS
- JavaScript
- JSONPlaceholder REST API

## Chức năng

- Hiển thị danh sách bài viết
- Lấy dữ liệu từ JSONPlaceholder API
- Responsive Grid
- Blog Detail với Dynamic Route `/blog/[id]`
- Điều hướng giữa Blog Listing và Blog Detail
